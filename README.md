# Ejercicios de React

Colección de ejercicios prácticos realizados durante el aprendizaje de React. Cada ejercicio es una pequeña aplicación independiente que trabaja conceptos como estado, eventos, efectos y almacenamiento local.

## Tecnologías

- React 19
- Vite
- CSS

## Ejercicios

| # | Título |
|---|--------|
| 1 | Cambiador de Color de Fondo |
| 2 | Contador de Clics |
| 3 | Lista Dinámica |
| 4 | Filtro de Búsqueda en Tiempo Real |
| 5 | Calculadora Sencilla |
| 6 | Temporizador con Inicio, Pausa y Reinicio |
| 7 | Generador de Contraseñas Aleatorias |
| 8 | Contador de Palabras y Caracteres |
| 9 | Lista de Tareas con LocalStorage |

## Instalación y uso

```bash
npm install
npm run dev
```
